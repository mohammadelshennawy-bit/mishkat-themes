# مشكاة ثيمز — Mishkat Themes

تطبيق أندرويد من «مشكاة»: ١٣ خلفية (هوية مشكاة وصور طبيعية)، وساعة أنالوج حية لشاشة القفل بثلاثة تصاميم مع حالة البطارية، و٢٢ أيقونة.

- البناء تلقائي عبر GitHub Actions (`.github/workflows/android.yml`).
- لإصدار نسخة: Releases ← Create a new release بوسم مثل `v1.0.0`، فيُرفق ملف `mishkat-themes.apk` بالإصدار.
- مفتاح التوقيع الثابت يُضاف كـ Secret باسم `ANDROID_DEBUG_KEYSTORE`.
